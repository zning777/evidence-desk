# 溯证｜个股多维诊断与证据验证

面向希望核查公司表现、但不愿把一段 AI 总结当成结论的个人研究者。单标的原型：美的集团（000333.SZ），固定财务截面：2026H1 对 2025H1，合并累计半年。

## 核心产品选择

从问题而不是指标堆砌出发：识别研究重点 → 组织正面、负面与交叉证据 → 钻取原值、公式及来源 → 留下明确的待验证问题。证据方向相对于研究命题，不是股票评级。交叉证据说明范围或表现需要拆开，不把两个同时成立的事实称为逻辑矛盾。

支持三条研究路径：

1. 归母增长、扣非下降：核对利润口径、归属范围与非经常性差额。
2. 现金质量：同时呈现经营现金流、合并净利润、应收占用和应付支持。
3. 收入与毛利：区分收入规模、毛利金额与毛利率。

## 如何演示

打开首页后默认是明确标注的「预设研究示例」，没有假装调用模型。输入问题及评委访问口令，点击「开始研究」，成功后显示真实模型及耗时；点击证据卡看财务期次、标准化原值、公式、限制与深交所 PDF。右侧分析引用可以打开依赖事实与原文页。待验证卡展示下一步材料与改变判断的条件。页面和示例可公开查阅，只有服务端 AI 调用需要口令；口令不保存在浏览器，也不放进源码。

「保存研究」仅在当前浏览器保存问题、路径和时间，不是模型输出快照，也不跨设备同步。

## AI 角色：刻意收窄，但真实可运行

服务端调用 DeepSeek `deepseek-flash`，识别问题并选择、排序目录中的证据 ID 与解释关系 ID。只接受 `intent / fact_ids / relation_ids / question_ids` 四个字段。程序验证必需事实、反证、限制及依赖关系；数字、公式、引用和解释文字均由确定性程序与预核验关系库还原。

因此它不是自由写研报的聊天机器人，也不是任意金融论断的自动语义验证器。有限解释库覆盖不足时不能扩写为无证据结论。买卖建议、收益预测及其他公司问题拒绝研究；模型格式错误、截断、网络失败或缺失必要证据时不展示新结论。

默认页面、点击预设题、打开已存路径均不调用模型。主动研究才调用；同一问题的已校验结果在当前服务实例内缓存五分钟。缓存与每分钟六次限制是演示级、实例内保护，不是生产级分布式额度管理。

## 数据来源与口径

原文：[美的集团 2026 年半年度报告（深交所）](https://disc.static.szse.cn/disc/disk03/finalpage/2026-08-29/df25443f-d67a-4cc5-8bd6-6c3e681a9575.PDF)。`lib/research-data.json` 保存人工核对的公开披露字段、逐字段页码与两期值，未包含供应商原始接口响应。

- 原文千元 → 标准化人民币元（乘 1,000）→ 展示亿元；原值计算后再四舍五入。
- 2025H1 是本次报告的比较列，不代表最初披露版本快照。
- 归母 +1.66%、扣非归母 -25.31% 均由两期原值重算。2026H1 非经常性净额 68.51 亿元；比较期差额为 -2.22 亿元。
- 会计差额勾稽不是经济因果归因。扣非不直接等于主营利润。汇兑、衍生及权益项目按税前合并口径分别列示，不能与税后归母净额直接混算。
- 现金流倍数的分母用合并净利润，而不是归母利润；合并现金流包含金融业务。
- PDF 链接使用 `#page=`，阅读器不支持跳转时需手动按页码查找。

财报是固定证据包，不是实时流。网页通过服务端扶摇接口获取价格快照、估值及美的/海尔/格力三家公司样本；展示供应商时间和抓取时间，五分钟内复用缓存，不承诺实时刷新。历史区间固定截至 2026-10-21，从股票与沪深300的21个共同完整交易日计算20个交易区间的价格变动和最大收盘回撤。美的使用前复权收盘，沪深300为价格指数，不宣称全收益或因果归因。同行倍数不构成行业排名，也未完成业务结构和会计口径调整。报告后新闻和公告尚未持续接入。

## 本地运行

需要 Node.js ≥ 22.13.0。安装依赖后启动：

```sh
npm run install:ci
npm run dev
```

本地 Worker 从项目根目录 `.dev.vars` 读取 `DEEPSEEK_API_KEY`、`FUYAO_API_KEY` 和 `DEMO_ACCESS_CODE`；变量名称见 `.env.example`，实际值不得提交。缺少配置时仍可看财报示例，对应服务明确提示未配置。生产环境使用 Sites 的秘密变量，不把密钥放进浏览器或源码。评委口令单独通过提交说明传递；更换口令需修改秘密变量并重新部署。

检查与构建：

```sh
node --test tests/*.test.mjs
npx tsc --noEmit
npm run build
```

保留了 Sites/Vinext 的 Worker 和构建集成。线上地址为 https://evidence-desk-a-share-20261022.wiryhake17.chatgpt.site ，以实际部署和访问验证记录为准。本地地址不能作为评委提交 URL。页面由 Sites 访问策略控制，AI 口令在服务端检查，不以隐藏按钮充当鉴权。每分钟六次及缓存均为实例内演示保护，不是分布式生产配额；访问口令不要提交到公开仓库。
