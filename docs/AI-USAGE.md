# AI 使用与验证说明

## 开发协作

AI 辅助研究问题收敛、数据核对、测试设计与代码实现。人工披露字段与程序重算相结合；不是直接复制模型写出的股票结论。

早期尝试自由生成解释时，发现混用归母与合并口径、过度归因及将会计差额当经济原因的风险，因此未将这些输出直接迁入网页。

## 产品运行时

采用受控选择与确定性渲染：用户问题及非敏感证据目录发送至 DeepSeek。密钥只在服务端使用；浏览器不接收原始模型生成文字。模型只能输出目录 ID，后端结构及依赖校验后才展示。

这是实际能力收窄，不应宣传为自动理解并验证任意金融结论。解释内容来自预核验关系库，AI 负责识别研究重点、选择和排序。

## 剩余风险

即使通过结构校验，模型也可能误选研究路径；有限样本不能证明对所有措辞都正确。生产化需要更全面的意图测试、分布式限流和预算上限、定期证据更新及财务专业复核。
