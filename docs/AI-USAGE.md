# AI使用与验证记录

## 使用工具及分工

- Codex：需求收敛、公开数据核对、代码实现、测试设计与上线协作。
- Claude Code：前期选题与范围建议，作为讨论输入，不作为事实依据。
- DeepSeek `deepseek-flash`：产品运行时识别研究重点，选择、排序证据与解释关系。

## 产品中的AI流程

用户问题及非敏感证据目录发送至DeepSeek。模型仅输出 `intent / fact_ids / relation_ids / question_ids`，服务端校验允许范围、必要反证、未知问题及依赖关系。数字与公式由程序计算，引用和解释文字由预核验关系库提供。

该方案覆盖美的集团的利润分歧、现金质量和收入毛利三条路径，不是任意金融结论的自动事实验证器。预设示例不调用模型，真实研究显示模型、耗时、请求标识、时间、tokens、证据版本和缓存状态。

## 对AI建议的核对与修正

1. 自由生成解释存在归母/合并口径混用、税前/税后项目相加及过度归因风险，改为受控证据选择与确定性渲染。
2. 会计差额用于勾稽，不解释为经济因果贡献；扣非归母利润不直接等于主营利润。
3. 经营现金流倍数使用合并净利润，并保留金融业务影响的边界。
4. 比较期非经常性净额为负，利润表中保留负差额与展示取整尾差。
5. 修正来源依赖不完整、灰字排版和市场数据时效保护不足。
