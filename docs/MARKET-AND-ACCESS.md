# 市场背景与访问边界

六个观察入口：经营质量、财务趋势、估值、行情特征、行业位置参考、重要事件与风险。前两项提供财报深钻，后三项市场观察提供口径/区间/来源展开；事件与风险仅覆盖当前报告，不冒充持续资讯监测。

市场数据仅由服务端请求固定接口，前端不接触扶摇 Key，不提交供应商完整原始响应到源码。接口失败、行情涨跌字段冲突、历史口径错误、重复日期或共同交易日不足时，不计算相关指标。

历史比较使用固定截至2026-10-21的21条共同完整收盘，形成20个交易区间。没有把当日未收盘 K 线混入历史区间。PE TTM / PB MRQ 为供应商口径，负值标记不可用；没有用样本倍数给行业排名。

公开页面允许直接查看财报示例。AI POST 必须携带与服务端秘密变量匹配的访问口令，缺失/错误返回401并在模型请求之前拒绝；口令未配置返回503。真实密钥、口令均不在源码、前端包或公开 README 中。浏览器输入口令后只保留在本次页面状态，不写持久存储。

调用限制与缓存是演示级实例内保护，非分布式总预算。持有口令者仍可消耗余额，应只向评委提供，测评结束后撤销或轮换并暂停模型调用。
