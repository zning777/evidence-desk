# 数据与访问边界

## 多维观察范围

提供经营质量、财务趋势、估值、行情特征、行业位置参考、重要事件与风险六个入口。财务维度支持原值深钻；市场维度提供口径、区间及来源；事件与风险覆盖本期报告，未接入持续资讯监测。

## 时间与数据质量

财报固定为2026H1对2025H1。市场数据由服务端扶摇接口获取，完整供应商响应不随前端返回。

快照与估值的供应商时间超过24小时、超前5分钟、异常或误传为秒级值时，停止相应数值展示。这是接口时点检查，不等于交易日历校验或最新成交保证；最新成交时点未独立核验。

历史比较固定截至2026-10-21，21个共同收盘形成20个交易区间。日期重复、区间不足、未覆盖截止日、复权错误或字段冲突时停止计算。美的采用前复权收盘，沪深300采用价格指数，不构成全收益比较。

PE TTM与PB MRQ采用供应商口径，无效倍数标记不可用。美的、海尔、格力为三家公司样本，未完成业务结构及会计差异调整，不作为行业排名或估值评级。

## 访问机制

页面、预设研究及证据钻取公开可用。AI接口采用服务端口令认证，缺失或错误返回401，未配置返回503；鉴权在模型请求之前执行。口令仅保留于当前页面状态，API密钥由服务端秘密变量管理。

五分钟缓存和每分钟六次调用限制均为实例内保护，不是分布式总预算或生产级额度管理。模型输出经结构与证据依赖校验后展示；调用失败时保留原研究并明确标记未生成本次结果。
